# Security policy

## Supported version

Security fixes are currently targeted at the latest V9 branch/release.

## Reporting

Do not post credentials, access tokens, private keys, personal secrets, or
unredacted sensitive configuration in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use
the repository's Security interface. Otherwise, open a minimal issue asking the
maintainer for a private reporting channel without including exploit details or
secrets.

## Scientific correctness

A physics/modeling error is normally a correctness issue rather than a software
security vulnerability. Use the Physics Validation issue template for those
reports.
